# ズボ管 PWA（無料優先スターター）

## できること
- 授業名、課題名、提出期限の登録・編集・削除
- 未完了／今日が期限／期限切れ／完了済みの絞り込み
- 16色の科目カラー
- 完了にするとアプリ内の期限チェック対象から除外
- ホーム画面アプリ向け manifest / service worker / push受信イベントの土台
- 課題データは端末ブラウザの localStorage に保存

## 重要：バックグラウンド通知について
このスターターは、アプリを開いている間のリマインドと、Web Pushを受信するService Workerの土台までです。**アプリを終了している間に課題ごとの通知を確実に送るには、Web Pushの送信サーバー・通知予約処理・課題データの同期が別途必要です。** 静的ホスティングに置くだけでは、終了中の通知は送れません。`sw.js` の push イベントはサーバーから push が届いたときに通知を表示しますが、送信サーバーはまだ設定していません。

## iPhoneだけで公開する大まかな手順
1. GitHubアカウントを作る／ログインする。
2. 新しい公開リポジトリ `zubokan-pwa` を作成する。
3. このZIPをiPhoneの「ファイル」アプリで展開し、含まれるファイルをリポジトリのルートへアップロードする。
4. GitHubのリポジトリで Settings → Pages → Build and deployment から `Deploy from a branch`、`main`、`/(root)` を選んで保存する。
5. 公開URLをSafariで開く。GitHub Pagesの公開反映には数分かかる場合がある。
6. Safariの共有ボタン →「ホーム画面に追加」でズボ管を追加する。
7. ホーム画面からズボ管を開き、「通知設定」を押して許可する。

## 次に必要な作業（アプリ終了中の通知）
- プッシュ通知サービスとサーバー側の秘密鍵を安全に設定
- iPhoneでホーム画面アプリから通知購読を作成
- 課題データをサーバーにも保存し、期限ごとの通知時刻を予約
- 課題完了・編集・削除時に、予約済み通知をキャンセル／更新
- iPhoneでアプリを閉じてテスト通知を受信できるか確認

## 注意
- GitHub Pages上のPWAはWebアプリであり、App Storeのネイティブアプリではありません。
- iPhoneのWeb PushにはiOS/iPadOS 16.4以降、ホーム画面への追加、通知許可が必要です。
- localStorageの課題は端末／ブラウザ内に保存されます。Safariの履歴・Webサイトデータ削除などで消える可能性があるため、重要な課題は別途バックアップしてください。
